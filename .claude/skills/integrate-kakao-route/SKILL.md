# 카카오모빌리티 거리 조회

## 1. 검증

1. `docs/kakao-mobility.md`의 검증 항목을 읽는다.
2. 카카오 공식 개발자 문서에서 각 항목을 확인한다. 블로그, 예제 저장소, 기억에 의존하지 않는다.
3. 항목마다 결과, 출처 URL, 확인일을 기록한다. 확인되지 않으면 `확인 불가`로 남긴다.
4. 결과를 사용자에게 보고하고, 제휴 승인이나 유료 조건, 키 노출 위험처럼 결정이 필요한 항목은 확정을 받는다. 결과가 `docs/decisions.md`의 A-4와 다르면 함께 보고한다.

## 2. 구현

공식 API로 거리를 조회할 수 없으면 수동 입력과 인터페이스까지만 구현하고, 자동 조회는 미연동으로 표시한다.

1. `domain`에 거리 조회 인터페이스와 결과 타입을 정의한다.
2. 수동 입력 흐름을 먼저 구현한다.
3. `data`에 검증된 필드와 단위만 사용해 구현체를 작성한다. `instructions/data.md`를 따른다.
4. `app`의 DI에서 구현체를 연결한다.
5. 응답 변환과 실패 처리를 가짜 응답으로 테스트한다.

## 3. 실제 연동 확인

1. 필요한 인증키는 사용자에게 `local.properties` 항목으로 설정하도록 요청한다. 키 값을 대화나 문서에 요구하지 않는다.
2. 실제 호출로 거리를 받아 공식 문서의 단위와 일치하는지 확인한다.
3. 호출에 성공한 경우에만 `docs/kakao-mobility.md`의 연동 상태를 완료로 바꾼다. 키가 없어 호출하지 못했으면 `미확인`으로 두고 그대로 보고한다.
