# Data 규칙

외부 API 사실은 `docs/kakao-mobility.md`의 검증 결과만 근거로 한다. `미검증` 항목에 의존하는 코드는 작성하지 않는다.

- `domain`에 정의된 인터페이스를 구현한다. Retrofit, OkHttp 타입과 응답 DTO를 `data` 밖으로 노출하지 않는다.
- DTO는 domain 모델로 변환해 반환하고, 거리 단위 변환은 변환 함수에서 처리해 테스트한다.
- 네트워크, 인증, 응답 형식 오류를 구분해 domain의 실패 결과로 변환한다. 예외를 그대로 올리지 않는다.
- 인증키는 git에 포함되지 않는 `local.properties`에서 읽어 빌드 설정으로 주입한다. 소스, 문서, 로그, 테스트 데이터에 실제 키를 넣지 않는다.
- HTTP 로그는 디버그 빌드에서만 켜고, 인증 헤더는 가린다.
- 키가 없거나 연동 전이면 앱이 멈추지 않고 미연동 상태를 반환해 수동 입력으로 진행할 수 있게 한다.
