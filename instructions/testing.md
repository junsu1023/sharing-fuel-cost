# 테스트 규칙

- JUnit 기반 단위 테스트를 쓴다. 다른 테스트 라이브러리는 필요성을 설명하고 추가한다.
- 정산 필수 테스트 목록은 `docs/settlement-rules.md`를 따른다.
- 테스트 이름은 조건과 기대 결과가 드러나게 쓴다.
- 단위 테스트는 실제 네트워크를 호출하지 않는다. 거리 조회는 가짜 구현으로 대체하고, 실제 키를 쓰지 않는다.
- ViewModel 테스트에서는 성공, 실패, 수동 입력 전환 상태를 검증한다.
- 실패하는 테스트를 삭제하거나 기대값만 바꿔 통과시키지 않는다. 원인을 고치거나, 요구사항이 바뀐 경우 근거를 보고한다.
- 단위 테스트 통과는 실제 API 연동의 증거로 보고하지 않는다.
