# 차종별 표시연비

**현재 상태: 연동 완료.** 2026-11-01 실제 호출과 앱 화면으로 확인했다.

## 공식 문서 확인 내용 (2026-11-01)

[한국에너지공단_자동차 표시연비 목록 조회 서비스](https://www.data.go.kr/data/15139827/openapi.do)

- 요청: `GET https://apis.data.go.kr/B553530/CAREFF/CAREFF_LIST`
- 필수: `serviceKey`, `pageNo`, `numOfRows`. 선택: `apiType`, `q1`(업체명), `q2`(모델명), `q3`(등급), `q4`(출시년도)
- 응답 `body.items.item`: `DISPLAY_EFF`(표시연비), `URBAN_EFF`(도심), `HIGHWAY_EFF`(고속도로), `COMP_NM`, `MODEL_NM`, `YEAR`, `FUEL_NM`, `GRADE`, `CAR_KIND`, `ENGINE_DISPLACEMENT`, `GEAR_TYPE`, `RANGE_PER_CHARGE` 등
- 결과 코드: `00` 정상, `03` 데이터 없음, `10`, `11`, `01`, `02`, `05`, `99` 오류
- 이용허락범위 제한 없음, 수정일 2025-06-02

## 실제 호출 결과 (2026-11-01)

- `apiType=json`이 동작하고, 구조는 `response.body.items.item[]`이다. 결과가 없으면 `resultCode` 00에 `totalCount` 0이고 `item`이 없다.
- `q2`는 부분 일치다. `아반`으로도 아반떼가 나온다.
- 확인한 `FUEL_NM` 값: `휘발유`, `경유`, `LPG`, `전기`, `수소`, `전기+휘발유`
- 빈 값은 문자열 `NULL`로 올 수 있다.

## 확인하지 못한 내용

- `DISPLAY_EFF`의 단위. 문서에 없지만 값으로 볼 때 내연기관은 km/L다.
- `전기+휘발유`(플러그인 하이브리드)의 표시연비가 휘발유만 쓸 때의 값인지. 배터리를 쓰는 조건이 섞였다면 실제 기름값보다 낮게 계산될 수 있다.
- 호출 제한.

## 플러그인 하이브리드 전비 (2026-11-12 실제 호출로 확인)

`CAREFF_LIST`는 `전기+휘발유`(등급 `PHEV`)의 `DISPLAY_EFF`로 휘발유 연비(km/L) 하나만 준다. 전비는 [한국에너지공단_자동차 연비표시제도](https://infuser.odcloud.kr/oas/docs?namespace=15083023/v1)의 `한국에너지공단_자동차 표시연비 정보_20260424`에서 가져온다.

- 요청: `GET https://api.odcloud.kr/api/15083023/v1/uddi:c5d3f252-f55b-469c-8573-e53160dd9e69?page=1&perPage=1000&cond[등급::EQ]=PHEV&serviceKey=…`
- 키: 같은 공공데이터포털 계정의 키가 동작한다. 중계 서버는 `DATA_GO_KR_API_KEY`를 함께 쓴다.
- 필드: `모델명`, `제조(수입사)`, `차종`, `유형`, `복합_연비`, `도심_연비`, `고속도로_연비`, `1회충전주행거리`, `등급`. **유종 필드가 없다.**
- PHEV의 `복합_연비`는 `2.7 / 7.4`(전비 km/kWh / 휘발유 km/L)다. 앞 값을 쓴다. 2026-11-12 기준 115건.
- `cond[등급::EQ]`, `cond[모델명::LIKE]` 조건이 동작한다. Swagger에는 없고 실제 호출로 확인했다.
- 모델명을 공백을 빼고 비교하면 `CAREFF_LIST`의 PHEV 81종 중 68종이 맞는다. 맞지 않는 13종(BMW iPerformance, i8, 레인지로버 P510e 등)은 전비를 비워 사용자가 입력한다.

## 구현 기준

- 키: 중계 서버 비밀값 `DATA_GO_KR_API_KEY`(디코딩 키). 앱은 키 없이 중계 서버의 `/data-go-kr/`을 호출한다. (`docs/relay.md`)
- `전기`는 연료를 전기로 보고 `DISPLAY_EFF`를 전비(km/kWh)로 쓴다.
- `전기+휘발유`(PHEV)는 전기와 휘발유 중에서 고른다. 휘발유 연비는 `DISPLAY_EFF`, 전비는 위 odcloud 목록에서 찾는다. odcloud 목록은 앱이 떠 있는 동안 한 번만 받는다. 전비를 찾으면 전기를, 못 찾으면 휘발유를 먼저 고르고, 전기로 바꾸면 전비 칸이 비어 사용자가 입력한다.
- 차종을 고르면 그 차가 쓰는 연료만 고를 수 있다. 연비를 직접 고쳐 차종이 해제되면 네 연료를 모두 고를 수 있다.
- 전기와 연료 사이를 바꾸면 단위가 달라지므로, 직접 입력한 연비와 유가도 지우고 새 연료의 값으로 채운다.
- 수소와 알 수 없는 연료는 결과에서 제외한다.
- 차종을 고르면 연비 칸과 연료 종류를 채우고, 유가를 직접 고치지 않았다면 평균 유가도 그 연료로 바꾼다.
- 연비를 직접 고치면 선택한 차종을 해제한다.
- 고른 차종은 저장하지 않는다.
- 표시연비는 공인 값이라 실제 연비와 다를 수 있다.
