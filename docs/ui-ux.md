# UI/UX 명세

MVP의 화면과 UI 상태를 정의한다. 화면 구성은 기획의 입력 항목과 결과 항목에서 도출했고, 시각 디자인은 `docs/decisions.md`의 D-6, D-7을 따른다.

## 사용 흐름

1. 경로와 참여자, 차량 정보를 입력한다.
2. 거리를 조회하거나, 조회할 수 없으면 직접 입력한다.
3. 정산 방식을 고르고 계산한다.
4. 결과를 확인하고 복사하거나 공유한다.

## 입력 화면

| 항목 | 입력 형식 | 검증 |
|---|---|---|
| 출발지, 목적지 | 입력 방식은 D-5에 따름 | 필수 |
| 참여자 | 운전자 1명과 탑승자 0명 이상, 이름 | 이름 필수, 운전자는 삭제 불가 |
| 탑승자별 탑승 위치 | 출발지, 목적지와 같은 방식 | 거리 비례 분할에서 필수 |
| 차량 연비 | 숫자, km/L | 0보다 큼 |
| 리터당 유가 | 숫자, 원/L | 0보다 큼 |
| 정산 방식 | 균등 분할, 이동 거리 비례 분할 중 선택 | 필수 |
| 거리 | 자동 조회 값 또는 직접 입력 값, km | 0보다 큼 |

- 숫자 필드는 숫자 키보드를 쓰고, 단위를 필드 안에 표시한다.
- 오류는 해당 필드 아래에 표시한다. 입력이 유효하기 전에는 계산 버튼을 비활성화한다.
- 자동 조회와 직접 입력 중 어느 값인지 화면에서 구분할 수 있게 한다.

## 거리 조회 상태

| 상태 | 화면 동작 |
|---|---|
| 조회 전 | 조회 버튼과 직접 입력 필드를 표시 |
| 조회 중 | 진행 표시, 조회 버튼 비활성화 |
| 성공 | 거리 값을 채우고, 사용자가 수정할 수 있게 함 |
| 실패 | 원인을 알리고 재시도와 직접 입력을 함께 제시 |
| 미연동 | 자동 조회가 연동되지 않았음을 표시하고 직접 입력만 허용 |

실패 상태에서도 사용자가 직접 입력으로 정산을 끝낼 수 있어야 한다.

## 결과 화면

- 전체 주행 거리 (km)
- 예상 연료 사용량 (L)
- 전체 기름값 (원)
- 정산 방식
- 참여자별 이동 거리와 부담금
- 복사 버튼: 결과 텍스트를 클립보드에 복사하고 완료를 알림
- 공유 버튼: Android 공유 시트로 같은 텍스트를 전달
- 입력 화면으로 돌아가면 입력값을 유지

## 공통 기준

- 금액은 천 단위 구분 기호와 `원`을 붙여 표시한다.
- 터치 영역은 48dp 이상으로 하고, 아이콘 버튼에는 `contentDescription`을 넣는다.
- 작은 화면과 큰 글꼴에서도 입력 내용이 잘리지 않게 스크롤을 지원한다.
- 색상, 글꼴은 `SharingFuelCostTheme`의 값을 사용하고 화면에 직접 쓰지 않는다.
- 화면 문구는 `strings.xml`에 둔다.
