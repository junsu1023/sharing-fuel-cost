# UI/UX 명세

MVP의 화면과 UI 상태를 정의한다. 화면 구성은 기획의 입력 항목과 `docs/decisions.md`의 결정에서 도출했다.

## 디자인 방향

- 결과물은 Compose 코드로 만들고, 필요한 아이콘은 프로젝트 리소스로 생성한다. (D-6)
- 라이트와 다크 모드를 모두 지원한다. (D-7)
- 분위기와 색상은 Open Design으로 정한다. (D-7)
- 시안이 여러 개면 구현 전에 사용자에게 확인받는다. (D-6)

**선택한 시안: D "답부터 보기".** 군더더기를 덜어 내고 내야 할 금액을 가장 먼저 크게 보여 줘서, 차 옆에서도 몇 초 만에 확인하고 끝낼 수 있는 분위기다. 원본은 Open Design 프로젝트 `sharing-fuel-cost-design`의 `index.html`이다.

### 형태와 글꼴

- 모서리: extraSmall 6, small 10, medium 12, large 16, extraLarge 24 (dp)
- 글꼴: 시안은 Noto Sans KR이다. 앱은 파일을 넣지 않고 시스템 기본 글꼴을 쓴다.
- 구조: 카드 대신 `surface` 섹션을 전체 폭으로 쌓고 `background` 띠로 구분한다. 입력 섹션 제목은 문장형이다.
- 입력: 투명 컨테이너와 하단 선만 있는 `TextField`
- 버튼: 하단 고정 56dp, tonal과 filled를 1:1.6으로 배치. 정산 방식 버튼은 5:7로 나눈다.
- 금액: 합계 52sp, 개인 26sp ExtraBold. 색 없이 크기와 굵기로만 강조한다.
- 동적 색상(Material You)은 쓰지 않는다.

## 사용 흐름

1. 목적지를 입력하고, 출발지를 확인한다.
2. 탑승자와 탑승 위치를 추가한다.
3. 차량 연비와 유가를 입력하고 정산 방식을 고른다.
4. 위치가 모두 정해지면 거리가 자동으로 채워진다. 조회할 수 없으면 직접 입력한다.
5. 결과를 확인하고 복사하거나 공유한다.

주행 중 위치를 측정하지 않는다. (A-2)

## 입력 화면

| 항목 | 입력 형식 | 검증 |
|---|---|---|
| 출발지 | 현재 위치가 기본값, 지도 화면에서 검색하거나 지도로 변경 가능 | 필수 |
| 목적지 | 지도 화면에서 검색하거나 지도로 선택 | 필수 |
| 탑승자 | 0명 이상, 이름 | 이름 필수. 운전자는 앱 사용자 본인이라 입력하지 않는다 |
| 탑승자별 탑승 위치 | 지도에서 선택, 탑승자마다 한 곳씩 여러 곳 선택 가능 | 탑승자마다 필수 |
| 경유 순서 | 탑승 위치를 추가한 순서, 변경 가능 (A-3) | |
| 내 차 | 모델명으로 검색해 선택. 연비와 연료 종류를 채움. 선택 사항. 연비를 입력하면 "내 차로 저장"을 표시하고, 저장한 차는 앱을 열 때 자동으로 채움. 저장한 값과 같으면 "저장 삭제"를 표시 | 한 대만 저장 |
| 차량 연비 | 차종 선택 값 또는 직접 입력, 숫자, km/L | 0보다 큼 |
| 연료 종류 | 휘발유, 경유, LPG 중 선택 | 평균 유가 선택에 사용 |
| 리터당 유가 | 오피넷 전국 평균이 기본값, 숫자로 수정 가능, 원/L | 0보다 큼. 기준일과 출처 표시 |
| 정산 방식 | 균등 분할, 이동 거리 비례 분할 중 선택 | 필수 |
| 거리 | 자동 조회 값 또는 직접 입력 값, km | 0보다 큼 |

- 숫자 필드는 숫자 키보드를 쓰고, 단위를 필드 안에 표시한다.
- 오류는 해당 필드 아래에 표시한다. 입력이 유효하기 전에는 계산 버튼을 비활성화한다.
- 자동 조회와 직접 입력 중 어느 값인지 화면에서 구분할 수 있게 한다.
- 직접 입력할 때는 전체 주행 거리와 탑승자별 이동 거리를 입력받는다.

## 현재 위치 상태

| 상태 | 화면 동작 |
|---|---|
| 권한 요청 전 | 앱을 처음 실행하면 시스템 권한 요청을 먼저 띄움. 거부하면 다시 자동으로 묻지 않고 "현재 위치 사용" 버튼으로 요청 |
| 확인 중 | 출발지 필드에 진행 표시, 주소 검색은 계속 허용 |
| 성공 | 현재 위치의 주소를 출발지에 채움 |
| 권한 거부, 실패 | 원인을 알리고 주소 검색으로 입력하게 함 |
| 권한 차단 | 시스템이 더 이상 묻지 않으면 "설정 열기"로 앱 설정을 열고, 허용 후 돌아오면 바로 현재 위치를 채움 |

출발지를 정할 때 현재 위치를 한 번만 가져오며, 계속 추적하지 않는다.

## 주소 입력 화면

지도를 쓸 수 없을 때의 대체 화면이다. 지도 화면의 "주소로 입력"으로 들어온다.

- 검색어 입력, 결과 목록, 결과 없음, 검색 실패 상태를 표시한다.
- 입력을 멈추고 300ms가 지나면 자동으로 검색한다. 별도 검색 버튼은 없고 키보드의 검색 키로 바로 검색할 수 있다.
- 결과를 고르면 입력 화면의 해당 필드로 돌아간다.

## 지도 선택 화면

출발지, 목적지, 탑승 위치가 모두 이 화면을 쓴다. 입력 화면의 위치 행 어디를 눌러도 열린다. 지도에서 위치를 눈으로 확인한 뒤 확정한다.

- 아직 고르지 않은 출발지, 목적지로 들어오면 검색창에 바로 입력할 수 있다.

- 지도를 움직이거나 누르면 그 위치가 화면 중앙 핀으로 옮겨지고, 주소를 표시한다. 주소가 없는 위치(바다 등)는 확정할 수 없다.
- 지도 위 검색창에서 주소나 장소를 검색해 고르면 지도가 그 위치로 이동한다.
- 지도 타일은 다크 모드에서도 밝게 표시된다. 주변 UI만 다크 토큰을 따른다.
- 이미 선택한 다른 탑승 위치도 지도에 표시한다.
- 확인 후 입력 화면의 해당 탑승자로 돌아간다.
- 지도를 쓸 수 없으면 원인을 알리고 주소 검색으로 입력하게 한다.

## 거리 조회 상태

| 상태 | 화면 동작 |
|---|---|
| 위치 미완성 | 위치를 모두 고르면 채워진다고 안내하고 직접 입력 필드를 표시 |
| 조회 중 | 진행 표시, 계산 버튼 비활성화 |
| 성공 | 거리 값을 채우고, 사용자가 수정할 수 있게 함 |
| 실패 | 원인을 알리고 "다시 조회"와 직접 입력을 함께 제시 |
| 좌표 없음 | 지도에서 고르지 않은 위치가 있으면 다시 고르거나 직접 입력하도록 안내 |
| 경로 변경 | 위치, 탑승자, 순서가 바뀌면 이전 거리를 지우고 다시 조회. 직접 고친 값도 교체 |

실패 상태에서도 사용자가 직접 입력으로 정산을 끝낼 수 있어야 한다.

## 결과 화면

- 경로: 출발지 → 탑승 위치들(경유 순서) → 목적지. 공유 문구에도 같은 경로를 넣는다.
- 전체 주행 거리 (km)
- 예상 연료 사용량 (L)
- 전체 기름값 (원)
- 정산 방식
- 참여자별 이동 거리와 부담금
- 복사 버튼: 결과 텍스트를 클립보드에 복사하고 완료를 알림. Android 13 이상은 시스템이 복사 확인을 띄우므로 앱은 12L 이하에서만 알림
- 공유 버튼: Android 공유 시트로 같은 텍스트를 전달
- 입력 화면으로 돌아가면 입력값을 유지

## 정산 기록

입력 화면 상단바의 기록 아이콘으로 연다.

- 결과 화면을 볼 때마다 자동으로 저장한다. 가장 최근 기록과 같은 계산이면 다시 저장하지 않는다.
- 최근 50건만 보관하고, 넘으면 오래된 기록부터 지운다.
- 목록: 최근 기록부터 계산 시각, 출발지 → 목적지, 탑승자 이름, 전체 기름값을 표시한다. 경유한 탑승 위치는 상세에서 본다. 기록이 없으면 계산하면 저장된다고 안내한다.
- 상세: 결과 화면과 같은 내용을 보여 주고, 제목은 계산 시각이다. 복사, 공유를 할 수 있고 상단바의 삭제로 지운다.
- 상세에서 뒤로 가면 목록, 목록에서 뒤로 가면 입력 화면으로 돌아간다. 입력값은 유지한다.

## 공통 기준

- 금액은 천 단위 구분 기호와 `원`을 붙여 표시한다.
- 터치 영역은 48dp 이상으로 하고, 아이콘 버튼에는 `contentDescription`을 넣는다.
- 작은 화면과 큰 글꼴에서도 입력 내용이 잘리지 않게 스크롤을 지원한다.
- 색상, 글꼴은 `SharingFuelCostTheme`의 값을 사용하고 화면에 직접 쓰지 않는다.
- 화면 문구는 `strings.xml`에 둔다.
- 입력 화면에서 뒤로가기를 누르면 "뒤로가기를 한 번 더 누르면 종료돼요" 토스트를 띄우고, 2초 안에 다시 누르면 앱을 종료한다. 다른 화면의 뒤로가기는 이전 화면으로 간다.
