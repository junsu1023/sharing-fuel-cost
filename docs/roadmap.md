## 현재 코드 상태

- 모듈: `app`, `presentation`, `data`, `domain`, `build-logic`
- `domain`에 정산 계산이, `presentation`에 입력, 결과, 주소 입력, 지도 안내 화면이 있다.
- `data`에 카카오 길찾기와 로컬 API 구현이 있고, Hilt로 `app`에서 연결한다.
- 지도 선택과 현재 위치는 미연동 표시 상태이며 주소 검색으로 대체한다.
