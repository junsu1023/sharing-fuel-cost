## 공개 출시 전 할 일

- 오피넷 키를 등록해 실제 응답을 확인한다. 수익 목적이면 석유공사와 협의한다.
- REST API 키를 서버 중계로 옮긴다. (A-6)
- 상업적 이용 조건을 운영정책과 제휴 담당자에게 확인한다.
- 릴리스 서명과 R8을 설정한다. 현재 `release`는 난독화와 최적화가 꺼져 있다.
- 시스템 글꼴 대신 Noto Sans KR을 넣을지 결정한다.

## 현재 코드 상태

- 모듈: `app`, `presentation`, `data`, `domain`, `build-logic`
- `domain`에 정산 계산이, `presentation`에 입력, 결과, 주소 입력, 지도 안내 화면이 있다.
- `data`에 카카오 길찾기와 로컬 API 구현이 있고, Hilt로 `app`에서 연결한다.
- 카카오맵 SDK로 탑승 위치를 고르고, Android 위치 API로 출발지를 채운다.
