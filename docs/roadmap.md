# 로드맵

단계가 끝나면 상태를 갱신한다.

## 현재 코드 상태

- 모듈: `app`, `presentation`, `data`, `domain`, `build-logic`
- `data`, `domain`에는 아직 소스가 없다.
- `MainActivity`는 템플릿 `Greeting` 화면을 표시한다.
- Hilt, Retrofit, OkHttp는 아직 추가되지 않았다.
