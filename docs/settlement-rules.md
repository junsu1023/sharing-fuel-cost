# 기름값 계산과 정산 규칙

## 계산식

```
연료 사용량(L) = 주행 거리(km) / 연비(km/L)
전체 기름값(원) = 연료 사용량(L) × 리터당 유가(원/L)
```

거리 조회 결과의 단위가 km가 아니면 계산 전에 km로 변환한다. 응답 단위는 `docs/kakao-mobility.md`의 검증 결과를 따른다.

## 정산 방식

**균등 분할**: 운전자의 출발지부터 목적지까지의 전체 기름값을 운전자를 포함한 참여 인원수로 나눈다.

**이동 거리 비례 분할**: 전체 기름값을 참여자별 이동 거리의 비율대로 나눈다.

```
참여자 부담금 = 전체 기름값 × (참여자 이동 거리 / 모든 참여자 이동 거리의 합)
```

운전자의 이동 거리는 전체 주행 거리다. 탑승자의 이동 거리 정의는 D-3에 따른다.

## 미결정 항목

`docs/decisions.md`의 D-1(잔여 금액), D-2(반올림 단위), D-3(탑승자 이동 거리)을 확정한 뒤 구현한다. 확정되면 이 문서에 규칙과 예시를 추가한다.

## 항상 지켜야 할 조건

- 모든 참여자 부담금의 합은 표시되는 전체 기름값과 정확히 일치한다.
- 부담금은 음수가 되지 않는다.
- 금액 계산에 `Double`을 누적해 쓰지 않는다. 최종 금액은 정수(원)로 다루고, 배분은 반복해도 같은 결과가 나오게 한다.
- 탑승자가 없으면 운전자가 전체 금액을 부담한다.
- 같은 입력에서 항상 같은 결과가 나온다. 잔여 금액 배정도 참여자 순서에 대해 결정적이어야 한다.

## 입력 오류

연비, 유가, 거리가 0 이하이거나 숫자가 아니면 계산하지 않고 오류로 처리한다. 거리 비례 분할에서 이동 거리의 합이 0이면 오류로 처리한다.

## 필수 테스트

- 계산식: 정상 입력, 소수 연비, 큰 거리
- 거리 단위 변환
- 균등 분할: 나누어떨어지는 경우, 잔여 금액이 생기는 경우, 탑승자 없음
- 거리 비례 분할: 이동 거리가 같은 경우, 다른 경우, 잔여 금액이 생기는 경우
- 부담금 합계가 전체 기름값과 일치
- 잘못된 입력 처리
