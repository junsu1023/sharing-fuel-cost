# 기름값 계산과 정산 규칙

## 계산식

```
연료 사용량(L) = 주행 거리(km) / 연비(km/L)
전체 기름값(원) = 연료 사용량(L) × 리터당 유가(원/L)
```

- 전기차는 연비 대신 전비(km/kWh), 유가 대신 충전비(원/kWh)를 넣고 같은 식으로 계산한다. 연료 사용량은 kWh로 표시한다. (2026-11-12)
- 거리 조회 결과의 단위가 km가 아니면 계산 전에 km로 변환한다. 응답 단위는 `docs/kakao-mobility.md`의 검증 결과를 따른다.
- 주행 거리는 출발지 → 탑승 위치들 → 목적지로 경유한 전체 거리다. (D-4)
- 전체 기름값은 1원 단위로 반올림한다. (D-2, A-1)

## 정산 방식

**균등 분할**: 전체 기름값을 운전자를 포함한 참여 인원수로 나눈다. 1원 미만을 버리고, 남는 금액은 누구에게도 배정하지 않는다. (D-1, A-1)

```
참여자 부담금 = 내림(전체 기름값 / 참여 인원수)
```

**이동 거리 비례 분할**: 운전자를 배려하는 방식이다. 탑승자는 함께 탄 구간도 혼자 탄 것처럼 자기 이동 거리의 기름값을 전액 내고, 운전자는 나머지를 낸다. (D-9)

```
탑승자 부담금 = 내림(전체 기름값 × 탑승자 이동 거리 / 전체 주행 거리)
운전자 부담금 = 전체 기름값 - 탑승자 부담금의 합
```

탑승자 거리 합이 전체 주행 거리보다 길면, 실제 기름값보다 더 걷지 않도록 전체 기름값을 탑승자 거리 비율로 나눈다. 운전자는 1원 미만 잔액만 낸다. (A-8)

```
탑승자 부담금 = 내림(전체 기름값 × 탑승자 이동 거리 / 탑승자 이동 거리의 합)
```

## 이동 거리

- 운전자의 이동 거리는 전체 주행 거리다.
- 탑승자의 이동 거리는 경로에서 그 탑승자의 탑승 위치부터 목적지까지의 거리다.
- 모든 참여자는 목적지에서 내린다. 하차 위치는 따로 입력받지 않는다. (D-3)

## 예시

연비 10km/L, 유가 1,600원/L, 경로가 출발지 → A 탑승 10km → B 탑승 5km → 목적지 20km일 때:

- 전체 주행 거리 35km, 연료 3.5L, 전체 기름값 5,600원
- 이동 거리: 운전자 35km, A 25km, B 20km

| 방식 | 운전자 | A | B | 합계 |
|---|---|---|---|---|
| 균등 분할 | 1,866원 | 1,866원 | 1,866원 | 5,598원 |
| 거리 비례 분할 | 1원 | 3,111원 | 2,488원 | 5,600원 |

위 거리 비례 분할은 탑승자 거리 합(45km)이 전체 거리(35km)보다 길어 5,600원을 25:20으로 나눈 경우다.

탑승자 거리 합이 전체 거리 이하인 예시: 전체 100km, 10,000원, 탑승자 60km와 20km이면 탑승자는 6,000원, 2,000원을 내고 운전자는 2,000원을 낸다.

## 항상 지켜야 할 조건

- 균등 분할의 부담금 합계는 전체 기름값 이하이고, 차이는 참여 인원수보다 작다.
- 이동 거리 비례 분할의 부담금 합계는 전체 기름값과 정확히 일치한다.
- 부담금은 음수가 되지 않는다.
- 금액 계산에 `Double`을 누적해 쓰지 않는다. 전체 기름값을 정수(원)로 확정한 뒤, 부담금은 정수 연산으로 구한다.
- 탑승자가 없으면 운전자가 전체 금액을 부담한다.
- 같은 입력에서 항상 같은 결과가 나온다.

## 입력 오류

연비, 유가, 거리가 0 이하이거나 숫자가 아니면 계산하지 않고 오류로 처리한다. 탑승자의 이동 거리가 전체 주행 거리보다 길면 오류로 처리한다.

## 필수 테스트

- 계산식: 정상 입력, 소수 연비, 큰 거리, 1원 단위 반올림의 올림과 내림 경계
- 거리 단위 변환
- 균등 분할: 나누어떨어지는 경우, 잔여 금액을 버리는 경우 (10,000원 3명 → 3,333원), 탑승자 없음
- 거리 비례 분할: 위 예시, 탑승자가 전 구간을 타는 경우, 탑승자 없음, 탑승자 거리 합이 전체 거리를 넘는 경우, 내림으로 남은 금액의 운전자 부담
- 균등 분할 합계와 전체 기름값의 차이가 참여 인원수보다 작음, 거리 비례 분할 합계가 전체 기름값과 일치, 음수 없음
- 잘못된 입력 처리
